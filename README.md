# Ukraine vs Zombies — Система стану гри та фізична взаємодія

## 1. Які типи колізій використані?

У проекті застосовано двовимірну фізичну підсистему Unity (**Unity 2D Physics**):

- **Тригери (`Collider2D.isTrigger = true`):**
  - **`BaseDefenseZone` (`BoxCollider2D`):** Фіксує перетин ворогами лінії оборони бази (`OnTriggerEnter2D`), завдає шкоди базі та знищує зомбі.
  - **`Enemy` (`BoxCollider2D` / `CapsuleCollider2D`):** Використовує `OnTriggerEnter2D`, `OnTriggerStay2D` та `OnTriggerExit2D` для виявлення веж, блокування власного руху та нанесення періодичної шкоди вежі в ближньому бою.
  - **`Projectile` (`CircleCollider2D`):** Визначає факт зіткнення снаряда з ворогом через `OnTriggerEnter2D` для ініціації прямої шкоди або детонації.
  - **`CollectibleItem` (`CircleCollider2D`):** Забезпечує безконтактний збір дропу при наближенні вежі або взаємодії.

- **Маски шарів (`LayerMask`):**
  - Використовується шар `Enemy` (Layer 8) для фільтрації колізій і просторових запитів, що усуває зайві перевірки між дружніми об'єктами.

## 2. Де застосовано `Raycast` або `Overlap`?

1. **`Physics2D.Raycast` — у скрипті `Tower.cs` (`ScanForTargetWithRaycast`):**
   - Промінь випускається горизонтально вправо вздовж своєї лінії (`Vector2.right * _range`) з маскою `_enemyLayerMask`.
   - Виявляє найближчого ворога на лінії вогню перед початком стрільби.

2. **`Physics2D.OverlapCircleAll` — у скрипті `Projectile.cs` (`Explode`):**
   - При влучанні вибухового снаряда сканує радіальну область (`_explosionRadius`) навколо точки контакту.
   - Завдає масової шкоди (AoE) усім ворогам у зоні ураження з урахуванням дистанції до епіцентру.

3. **`Physics2D.OverlapPointAll` — у скрипті `GameManager.cs` (`HandleWorldClicks`):**
   - Перевіряє координати кліку миші у світовому просторі (`ScreenToWorldPoint`).
   - Дозволяє гравцеві підбирати монети та бонуси (`CollectibleItem`), навіть якщо вони знаходяться під іншими об'єктами або в русі.

## 3. Чому саме такий метод перевірки обрано?

- **`Raycast` для веж:** Ідеально підходить для лінійного захисту (Lane Defense). Оскільки вежа стріляє суто прямо по своїй смузі, одновимірний промінь значно продуктивніший за періодичний пошук по списку чи великі колайдери виявлення, не створює накладних витрат на пам'ять і точно визначає пряму лінію видимості.
- **`OverlapCircleAll` для снарядів:** Оптимальний вибір для вибухів, оскільки фізичний імпульс/ударна хвиля поширюється рівномірно в усіх напрямках від центру влучання. Це дозволяє миттєво знайти всіх зомбі в радіусі вибуху за один системний виклик.
- **`OverlapPointAll` та `Triggers` для взаємодії:** Тригери не створюють фізичного відштовхування (відсутній ефект "штовхання" зомбі чи зупинки куль фізичними перешкодами), що забезпечує плавний і передбачуваний ґеймплей стратегії, де потрібна лише детекція подій без зайвих фізичних сил.

## 4. Як механіки впливають на Core Loop?

**Core Gameplay Loop:**  
`Спавн ворогів` ➔ `Виявлення (Raycast)` ➔ `Атака веж (Снаряди / Overlap-вибухи)` ➔ `Знищення зомбі та дроп монет` ➔ `Збір ресурсів (OverlapPoint/клік)` ➔ `Будівництво нових веж на сітці (Grid)` ➔ `Захист бази (BaseDefenseZone)` ➔ `Підвищення рахунку / Game Over при 0 HP`.

- **Динаміка ресурсів:** Знищення зомбі приносить монети як автоматично, так і через дроп, створюючи активність для гравця між тактичними рішеннями.
- **Економіка та темп:** Накопичені монети витрачаються на розміщення нових захисників на `Grid`, стримуючи наростаючий потік ворогів.
- **Критичний стан гри (`GameManager`):** Якщо зомбі прориваються крізь оборону до `BaseDefenseZone`, здоров'я бази знижується. Досягнення 0 HP активує стан **Game Over** з екраном підсумкового рахунку та можливістю миттєвого перезапуску (`R` або кнопка `Restart`).
